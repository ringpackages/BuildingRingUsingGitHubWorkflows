Binary release for macOS 64 bit
===================================================

To install 


(1) Install homebrew from http://brew.sh/

(2) Install Libraries
	cd ring/build
	./installdepmac.sh

(3) To be able to call ring from any folder 
	
	cd ring/bin
	sudo ./install.sh
	
(4) Run Ring Notepad
	
	cd ring/tools/ringnotepad
	ring rnote.ring

	Or using the Ring Package Manager
	ringpm run ringnotepad
