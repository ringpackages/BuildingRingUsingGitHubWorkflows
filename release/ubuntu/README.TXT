The Ring Programming Language
http://ring-lang.github.io/
===================================================
Binary release for Ubuntu Linux 64 bit
===================================================

To install 


(1) Install Libraries
	cd ring/build
	./installdepubuntu.sh

(2) To be able to call ring from any folder 
	
	cd ring/bin
	sudo ./install.sh
	
(3) Run Ring Notepad
	
	cd ring/tools/ringnotepad
	ring rnote.ring

	Or using the Ring Package Manager
	ringpm run ringnotepad
